# 修仙健身录 Unity Demo

This is a Unity UGUI prototype converted from the browser demo.

## Open

1. Open Unity Hub.
2. Add project from `E:\Cproduct\xiuxian`.
3. Open `Assets/Scenes/Main.unity`.
4. Press Play.

## Included Features

- Bottom navigation: 首页, 根基, 修炼, 境界, 记录.
- Body foundation input with seven-day update cooldown.
- BMR-based daily base spirit estimate.
- Daily cultivation task generation and task progress.
- Workout check-in rewards.
- Cultivation gain popup and realm progress effect.
- Realm breakthrough logic.
- Local persistence through PlayerPrefs.

## Notes

- The demo builds its UI at runtime from `Assets/Scripts/XiuxianFitnessApp.cs`.
- It uses built-in UGUI and does not require TextMeshPro setup.
- The UI is mobile portrait oriented.
